# Premium visual-lesson scripts (13 lessons)

These scripts are included as production-ready narration/storyboard outlines for the guided visual lesson player. They are not prerecorded MP4 files; no external video source was supplied, so the package does not pretend that hosted videos exist.

## Lesson 8: Shopping and Prices

**Learning goal:** Ask for an item, its price and a suitable quantity.

**Opening narration:** Welcome to lesson 8. Today we will practise shopping and prices. Listen carefully, repeat each phrase, and use it in a short conversation.

**Teach:**
- بِكَمْ؟ — How much?
- هَذَا — This (masculine)
- هَذِهِ — This (feminine)
- غَالٍ — Expensive
- رَخِيصٌ — Cheap
- أُرِيدُ — I want
- مِنْ فَضْلِكَ — Please

**Model phrase:** بِكَمْ هَذَا؟ — How much is this?

**Practice prompt:** Say the target expression aloud three times. Then create one new sentence using a vocabulary item from this lesson.

**Review:** Explain the meaning in English, then say the Arabic expression without reading it.
