IMPORTANT NOTES
- Academy learning statistics, saved words, reviewed words and streak are stored in this browser's local storage. They are not synchronised to Supabase or across devices.
- Premium visibility in the Academy is a front-end convenience check using the existing profiles membership and premium_until fields. It is not secure content protection. Do not place confidential/paid-only source material in public static files. Secure paid content needs server-side or database authorization.
- Daily challenge questions are a fixed practice set that appears daily; they are not generated from a remote daily content service.
- Arabic speech uses browser/device speech synthesis. Availability and voice quality vary by device.
- The new files passed JavaScript syntax checks. This package still needs live browser/device testing, including Free/Premium account checks and installation testing, before public launch.
