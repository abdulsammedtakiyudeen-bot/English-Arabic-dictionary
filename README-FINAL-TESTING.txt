PUBLISH AND TEST

1. Back up your current GitHub repository before replacing files.
2. Extract this ZIP and upload its contents to the repository root, preserving folders.
3. Wait for GitHub Pages to finish publishing.
4. On Android, close the installed PWA fully, reopen it while connected to the internet, and allow the new service worker to update.
5. Sign in once, close the app, then reopen it using the same installed app. It should return to the learning area while the saved session remains valid.
6. Open Profile and try changing the picture. If it fails, check Supabase Storage for an "avatars" bucket and authenticated upload policies. Never share passwords, access tokens, service-role keys or payment secrets.
7. Check homepage order: Discover Arabic first, Extra Arabic Resource Library below the introduction.

If the installed PWA continues showing old files, open the website in Chrome, refresh it, then close and reopen the installed app. Do not clear site data unless you are prepared to sign in again.
