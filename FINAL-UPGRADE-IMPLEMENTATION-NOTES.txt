REQUIRED SUPABASE SETUP BEFORE USING BACKEND FEATURES
1. Run supabase/migrations/20261103_notifications.sql in the Supabase SQL editor.
2. Deploy supabase/functions/delete-account/index.ts as the Edge Function named delete-account. Ensure SUPABASE_URL, SUPABASE_ANON_KEY and SUPABASE_SERVICE_ROLE_KEY are configured as function secrets. Never put the service-role key in config.js or any public file.
3. Review your foreign-key deletion and payment-retention rules before enabling account deletion in production. Auth user deletion cascades only where the database schema is configured to do so. Preserve legally required payment records.
4. Notification centre can display records once trusted server-side workflows insert genuine events. This ZIP does not fabricate notifications or automatically create every event trigger.
